# ScanProgramm

**ScanProgramm** is a desktop app that renames scanned documents instead of user. **It only works for PDF files**.

I made it for my part-time job. All my shifts was about scanning provided documents and renaming every PDF file by hand: company name, document number and date. 
So this is a tool i built for one specific very routine task. The program will be useful for you if you accept and scan documents such as receipt orders.

---

## What it looks like

After launching the program, the **main window** greets you:


<img width="695" height="628" alt="image" src="https://github.com/user-attachments/assets/0dcd6410-2ddc-4c1f-bdd3-079bac25ebc7" />


First of all, you need to set it up. You can open the **setup window** by clicking on the (`'Настройки'`) blue button, which is at the very bottom.
And now you're greeted by the settings window:


<img width="699" height="627" alt="image" src="https://github.com/user-attachments/assets/98f29443-372b-4aa4-b020-16f6061610c1" />



For the most part, you’ll only need to add two folders: the folder where your scanner saves the documents, and the folder where the program will save the renamed documents. The first one called 'Папка для сканов' and the second 'Папка готовых документов'. The both are highlighted in bold. You can select the required folders by clicking on the button to the right of the empty windows with the border. On the second tab, you can enter the name of your company. This way, you’ll make it clear to it which company not to include in the name. These settings will be enough. If you want to learn about all the remaining available features, I'll write about them below.
If you are ready, save your settings by clicking the button in the bottom right corner (`'Сохранить и начать работу'`). If you don't want to save them - click on the button to the left (`'Отменить'`)  

If you want to run an app, you need to click on the green button (`'ЗАПУСТИТЬ'`), to stop it just click on the same but now red button (`'ОСТАНОВИТЬ'`)
Now you can start scanning your documents, but make sure that your scanner scans to the folder you specified in the settings.

There is a chance, that a program won't be sure how to rename the pdf correctly. If that happens, **notifier** will appear in the right corner of your screen:


<img width="487" height="265" alt="image" src="https://github.com/user-attachments/assets/c1ecba3b-428e-4c4c-8f2a-352ac2a31f7b" />


To check the document up and teach a program how to name it you need to click on the purple button on the bottom of the notifier window (`'Проверить'`) or you can just ignore it by doing nothing or clicking on the button to the right (`'Игнорировать'`)

If you chose the first one, the **correction window** will appear:


<img width="887" height="722" alt="image" src="https://github.com/user-attachments/assets/fcfc36ef-ac43-4c9c-aeef-178cb993f1e4" />


On the left is a scan of the first page of the document, and on the right there are three empty windows where you will need to write: 1) the company name; 2) the document number; 3) the date.
After filling in, save by clicking the button at the bottom left (`'Сохранить и научить'`) or if you just want to skip this part just click on the button on the right (`'Пропустить'`) but then your document won't be named properly. If there is a checkmark under the fill‑in fields, an app will save these changes in memory, and the next time it encounters a similar document, it will be able to refer.
